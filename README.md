# kayralrics.com - paint | kayralrics.net

A browser-based drawing and image-editing app inspired by Windows Paint. It runs as a static page and does not require a server or third-party JavaScript packages.

## Run it

1. Open `index.html` in a current version of Chrome, Edge, or Firefox.
2. Open an image using **Open**, drag and drop a file onto the workspace, or paste an image from the clipboard.
3. To resize an image or canvas, choose **Canvas size** or use the **Image / canvas size** panel. Enter the new width and height in pixels. Enable **Scale image to new dimensions** to resample the image; disable it to change only the canvas bounds. Lock the aspect ratio to preserve proportions.
4. **Save** downloads a PNG. Use **Export** to choose another supported format.

The app can be hosted as a static website. To publish it on a domain, configure DNS and web hosting separately, then upload `index.html` to the host's public web directory. This package does not configure DNS or hosting.

## Features

- Pencil, brush, eraser, fill bucket, eyedropper, line, rectangle, ellipse, text, and crop tools
- Foreground/background colors, preset palette, brush size, and opacity
- Undo/redo, zoom, fit-to-screen, canvas resizing, and image resampling
- Open images, drag and drop files, and paste images from the clipboard in supported browsers
- Export to PNG, JPEG, WebP (when supported by the browser), BMP, single-frame GIF, SVG containing a raster image, and the app's JSON-based project format
- Keyboard shortcuts and local processing
- No external JavaScript packages, CDN, third-party tracking scripts, or app server dependencies

## Format limitations

No web app can universally open and export every file format. Some formats require additional or proprietary decoders. Image import depends on the browser's built-in decoders. Common PNG/JPEG/GIF/WebP/BMP files and sanitized SVG files can be tried; AVIF, ICO, and TIFF support varies by browser. This app does not include built-in decoders for PSD, HEIC, RAW, PDF, or XCF.

- GIF export does not create animation. It produces a single-frame, 256-color image without transparency and has a 4-million-pixel limit.
- SVG export embeds a PNG rather than editable vector paths.
- JPEG converts transparent areas to a white background.
- The project JSON stores the canvas as a PNG; it does not preserve layers or editable object history.
- To limit memory use, files are limited to 100 MB, each canvas dimension to 12,000 px, and the total canvas area to 30 million pixels.

## Security and validation

Files are processed locally and are not uploaded to a server by the app. SVG import removes scripts, event handlers, animations, and external resource references; the Content Security Policy blocks external connections and embedded objects. These measures are not an absolute security guarantee.

JavaScript syntax, HTML IDs, and label associations were checked. Sample files generated by the BMP and GIF exporters were opened with an independent image decoder. Full interactive browser testing could not be completed in the working environment because Chromium failed to start within the available time. Testing in supported browsers before deployment is recommended.
